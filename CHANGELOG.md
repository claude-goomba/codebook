# Changelog

## 1.1.0 - Merger

- Ship 112 built-in snippets across five languages, including 100 additional examples.
- Add same-language snippet selection, ordering, editable text combination, clipboard copying, and custom-library saving.
- Add a transparent open-book logo with a QR-like motif and colorful code marks.
- Include library and Merger regression tests.
- Package Codebook as a standalone project with downloadable web releases.

This release combines text only; automatic working-program integration and AI modes are not included.
